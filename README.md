## 🛠️ Entwicklungsumgebung

### Visual Studio Code + Claude Code
Wir verwenden **Visual Studio Code** (VS Code) als Entwicklungsumgebung und darin **Claude Code**, den KI-Programmierassistenten von Anthropic. 
In Claude Code beschreiben wir in normaler Sprache, was unser Spiel können soll. Claude schreibt und ändert dann den Code direkt in unseren Dateien.

**Downloads:**
- VS Code: <https://code.visualstudio.com>
- Claude Code: <https://claude.com/claude-code>

### KI-Modell: Claude Opus 5.5
Für die Code-Entwicklung nutzen wir das KI-Modell **Claude Opus 5.5** von Anthropic. Dieses Modell hilft uns beim:
- Schreiben von neuem Code
- Verstehen und Erklären von bestehendem Code
- Finden und Beheben von Fehlern
- Umsetzen kreativer Spielideen

### VS Code einrichten
1. VS Code herunterladen und installieren
2. Erweiterung **Claude Code** installieren und anmelden (benötigt ein Claude-Konto mit Abo)
3. `File → Open Folder` und den Projektordner `monte26` auswählen
4. Claude-Code-Panel öffnen und als Modell **Claude Opus 5.5** wählen

### Wichtige Einstellungen

**1. Autosave aktivieren:**
- In VS Code: `File → Auto Save` aktivieren
- So werden alle Änderungen automatisch gespeichert

**2. Live Server Erweiterung:**
- Erweiterung: **Live Server** von **ritwickdey**
- Ermöglicht direktes Testen der Spiele im Browser
- Bei jeder Änderung wird die Seite automatisch neu geladen
- Installation: In VS Code auf das Erweiterungs-Symbol klicken, nach „Live Server" suchen und installieren
- Start: Rechtsklick auf eine `.html`-Datei → „Open with Live Server"
